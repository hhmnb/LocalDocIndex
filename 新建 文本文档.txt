# 规则库目录索引工具

一个基于 Python Tkinter 的本地文件索引与筛选工具，支持虚拟滚动、多主题、文件内容复制、批量审核、提示词导出等功能。

## 功能特性
- 快速扫描指定文件夹下的所有文件（自动排除 `.idea` 目录）
- 虚拟列表渲染，支持数万文件流畅滚动
- 关键词实时过滤（防抖）
- 文件类型过滤：包含/排除指定扩展名，支持多选和自定义
- 一键复制单个文件内容或整个目录树结构
- 批量审核模式：粘贴 AI 返回的文档清单，自动隐藏未选中文件
- 可自定义提示词模板，导出给 AI 使用
- 三种内置主题（柔和深灰蓝、纯黑、浅色）
- 更改根文件夹、手动刷新、重置处理状态

## 使用方法
1. 运行 `python main.py`
2. 点击“更改文件夹”选择目标目录
3. 浏览文件列表，使用顶部关键词过滤或“过滤设置”按钮进行类型筛选
4. 点击文件右侧“复制”按钮复制文件内容
5. 使用底部按钮进行批量审核、导出提示词等操作

## 环境要求
- Python 3.6+
- 无需第三方库

## 注意事项
- 默认根路径为 `C:\Users\Administrator\Desktop\编程经验`，您可以在代码中修改 `DEFAULT_ROOT_PATH` 变量，或启动后通过界面更改文件夹。
